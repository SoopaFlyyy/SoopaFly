# Playmates

A Steam-first social discovery MVP: connect through what you play, not profiles or feeds.

## MVP concept
- Opt-in Steam connection
- Game-library overlap as the core matching signal
- Playtime and achievements as context
- Game-specific temporary groups
- No dating mechanics
- No built-in open-ended social feed
- Communication can ultimately hand off to the game itself
